# DeLaClaw

> A personal command center you own.

DeLaClaw is a zero-dependency, no-build, self-hosted personal dashboard. It runs entirely in the browser as vanilla JavaScript ES modules, with pluggable backends — Google Drive, Supabase, local SQLite, or in-memory demo.

## Features

- **Projects & Tasks** — Kanban-style project boards with task workflows
- **TODOs** — Categorised to-do lists with snooze, priority, and deadlines
- **Habits** — Recurring habit tracker with calendar view and streak stats
- **Flashcards** — Spaced-repetition flashcards and text revision decks
- **Lists** — Generic lists for anything that doesn't fit elsewhere
- **Vestiaire** — Wardrobe inventory tracker
- **Birthdays** — Birthday reminders with avatar photos

## Getting started

Head to the [Setup Guide](setup.md) to pick a backend and start using DeLaClaw in under 60 seconds.

## Philosophy

- No accounts, no subscriptions, no tracking
- Your data stays yours — self-host on Google Drive (free) or run locally
- Zero build step — just open `index.html`
