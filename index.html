Get Started

1

Sign in with Google

Click Connect on the login screen and sign in with your Google account. DeLaClaw will create a DeLaClaw/ folder in your Drive to store a single delaclaw-data.json file.

2

That's it

No API keys, no database setup. Your data lives in your Google Drive as a plain JSON file you can export or delete at any time.

2
3

This path requires a terminal and basic command-line knowledge.

1

Install Bun

Open a terminal and run:

curl -fsSL https://bun.sh/install | bash
2

Clone and start the server

git clone https://github.com/AntGro/DeLaClaw.git
cd DeLaClaw/server
bun run server.js

The database is created automatically on first run. Default port: 3737.

3

Connect

Open http://localhost:3737, select Local, and enter the server URL. No API key needed.
