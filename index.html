Get Started

Choose how you want to store your data.

1

Sign in with Google

Click Connect on the login screen and sign in with your Google account. DeLaClaw will create a DeLaClaw/ folder in your Drive to store a single delaclaw-data.json file.

2

That's it

No API keys, no database setup. Your data lives in your Google Drive as a plain JSON file you can export or delete at any time.

1

Create a free Supabase project

  1. Go to supabase.com/dashboard and create a free account (GitHub or email).
  2. Once logged in, create an organization (any name), then click New Project — pick a name and choose a region.

Copy the URL from your browser's address bar after creating the project.

Please enter a valid Supabase project URL

2

Run the database schema

In your Supabase dashboard, open the SQL Editor, paste the schema below, and click Run. If prompted about Row Level Security, choose Run without RLS — it is enabled later in the script.

Install Bun

          
Open a terminal and run:

          
curl -fsSL https://bun.sh/install | bash

        

      

      

        2
        

          
Clone and start the server

          
git clone https://github.com/AntGro/DeLaClaw.git
cd DeLaClaw/server
bun run server.js

          
The database is created automatically on first run. Default port: 3737.

        

      

      

        3
        

          
Connect

          
Open http://localhost:3737, select Local, and enter the server URL. No API key needed.
